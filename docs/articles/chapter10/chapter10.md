#  Глава 10. Docker

Докеризация позволяет упаковать приложение в контейнер для удобного развертывания и масштабирования.

Традиционно в Dockerfile используется мультистейдж-сборка: проект собирается в одном слое, а затем только необходимые
артефакты переносятся в финальный слой, что уменьшает итоговый размер образа.

В Nx все зависимости хранятся в корневом package.json, из-за чего при отдельной сборке каждого проекта в Docker
приходилось бы каждый раз устанавливать одни и те же зависимости.

Хотя можно было бы создать общий базовый слой с зависимостями, Nx уже обеспечивает оптимизированный процесс сборки.
Поэтому логичнее использовать для контейнеризации готовые артефакты, которые генерирует Nx.

Такой подход позволяет сохранить все преимущества монорепозитория, избежав избыточного дублирования зависимостей в
Docker-слоях. В результате итоговые образы получаются гораздо компактнее.

npx nx g setup-docker --project=web --outputPath=web
