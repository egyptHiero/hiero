# Глава 4. Подключение VitePress

Мне хотелось не просто написать программу для перевода иероглифов, но также написать интересную и
полезную историю, и про иероглифы, и про технологии. Убить, так сказать, сразу двух зайцев. Даже трех - еще и
научиться понимать египетские иероглифы (небольшой спойлер - этот заяц выжил).

При этом, мне не хотелось писать в формате статьи - во-первых, есть слишком большое количество мелких деталей, которые в
статье будут избыточными. Хотелось вести нечто-то вроде блога, описывать для себя и для безмерно благодарных
потомков весь непростой процесс создания данного приложения. Во-вторых, статья обычно бывает посвящена только одной
линии - в ней сложно будет уместить вместе и иероглифы и web-технологии, а вот в блоге - запросто.

И раз уж имеется желание вести одновременно и блог и разработку, то стоит это делать в одном репозитории.
А опубликоваться можно на [github.pages](https://pages.github.com/). И хотя там имеется встроенный генератор
статических сайтов
[jekyll](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll),
мне не хотелось добавлять в проект Ruby - и я решил выбрать что-нибудь более тайпскриптовое,
а именно [VitePress](https://github.com/vuejs/vitepress).

### Vitepress

`Vitepress` это генератор статических файлов, на базе Vite и Vue.js, созданный для быстрой разработки документации с
поддержкой Markdown, встроенным SSR и темами. Он сочетает простоту настройки с высокой
производительностью, предлагая горячую перезагрузку, предзагрузку модулей и удобное API для кастомизации.

Не будем добавлять `VitePress` как отдельный проект `Nx`, просто заведем папку `docs`, добавим зависимости и запустим
инициализую -

```bash
$ npm i -D vitepress
$ npx vitepress init
```

Теперь нужно исправить небольшую проблему - `VitePress` создает директорию `.vitepress/cash` и складывает туда свои
файлы, в том числе `package.json`, а это ломает сборку `Nx`. Поэтому стоит добавить директорию `docs` в `.nxignore`.

Ну вот, можно вести разработку и блог одновременно -

```bash
$ npx nx dev docs
```

### Автогенерация сайдбара

Для автоматической генерации оглавления и переходов вперед-назад добавил
плагин [vitepress-sidebar](https://vitepress.dev/reference/default-theme-sidebar)

```bash
$ npm i -D vitepress-sidebar
```

и прописал настройки в файле `.vitepress/config.mts`.

### Деплой на github pages

Процесс деплоя детально описан на [официальном сайте](https://vitepress.dev/guide/deploy#github-pages).
Правда есть пара тонкостей:

- во-первых, задать бранч в настройках приложения - `https://github.com/[name]/[project]/settings/pages`
- во-вторых, задать базовый путь (base) в настройках `vitePressOptions`
