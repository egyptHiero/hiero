# Бесконечный скроллинг

Получение данных из key-value хранилища LevelDB происходит последовательно, через интератор. Поэтому нельзя подключить
обычную пагинацию. Поэтому, добавим в таблицы автроподгрузку данных при скроллинге в низ таблицы. Для этого добавим
[react-intersection-observer](https://github.com/thebuilder/react-intersection-observer)
Он предоставляет хук для отслеживания присутствия (или отсутствия) элемента в зоне видимости экрана (viewport).

В свою очередь, в react-query есть хук
[useInfiniteQuery](https://tanstack.com/query/latest/docs/framework/react/reference/useInfiniteQuery)
для имплементации бесконечной подгрузки данных. Он объединяет результаты запросов в массив `pages` и подгружает
данные по требованию.
